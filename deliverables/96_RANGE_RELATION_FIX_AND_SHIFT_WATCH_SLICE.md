## 2) الـpredicate المُبلَّغ عنه `low <= level` — التمييزات الصريحة

كنت أسمّيه "traded at or through" — **والتسمية خاطئة**، والمثال الذي أشرت إليه كاشف: شمعة **بالكامل تحت** المستوى تحقق `low <= level` أيضاً. التصنيف الصريح لما تثبته الملاحظات (E):

| الحالة | الشرط (من OHLC المنشور) | ما تثبته |
|---|---|---|
| النطاق **يحتوي** المستوى | `low <= level <= high` | المستوى كان **ضمن النطاق المُبلَّغ** فقط — لا اتجاه داخلي، لا تسلسل داخل الشمعة، لا أوامر عند المستوى |
| النطاق **بالكامل تحت** | `high < level` | الشمعة كلها تحت المستوى (تتجاوزه سلفاً) — **لا** تحقق "الوصول للمستوى" |
| النطاق **بالكامل فوق** | `low > level` | الشمعة كلها فوق المستوى (قفزت عليه) — **لا** تحتويه |
| **انتقال فعلي عبر** المستوى (عندما تثبته الملاحظات) | انتقال إغلاق-إغلاق بين شمعتين مكتملتين: `prev_close > level >= close` (هبوط) أو `prev_close < level <= close` (صعود) | **انتقال عند دقة الشمعة** بين الإغلاقين — المسار داخل الشمعة غير مُثبَت |

**الإصلاح الضيق (E)**: مسار المرشَّحين يستعمل الآن **احتواء النطاق** `low <= level <= high` (+ إحصاء ترتيبي + اتجاه الشمعة)، والنص يقول "the reference level lies within this bar's reported range" مع `does_not_establish` صريح (الاتجاه/التسلسل/الأوامر) و"not called 'traded through'". وسُجِّلت `level_relation` لكل مرشَّح: `level_entered_range_at_this_bar` (مقارنة بالشمعة السابقة) + `close_side_of_level`. حدث التأكيد يبقى بصياغة المصدر "is traded through" لكن مع تحفظ دقة مرفق (ارتفاع الشمعة اللاحقة يتجاوز المستوى؛ التسلسل الداخلي غير مُثبَت). **لا نسبة ولا عدد شموع ولا عتبة جديدة** — اختبار D يثبّت الغياب عددياً.
