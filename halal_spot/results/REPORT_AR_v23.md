## (5) إثبات Zero-Lookahead

```
1198:            # feed completed 4H bars up to t (causal: <= t)
1200:                   and tf_4h.index[ptr[(sym, "4h")]] <= t):
1219:                if t in tf.index:        # الفريمات التنفيذية عند إغلاقها فقط
  ~:        if idx <= s.gate_idx:             # ZERO-LOOKAHEAD gate قبل الملء
  ~:        if any(b <= c <= t for b, t in self.consumed):
```
- الفريمات العليا (4H) تُغذّى بمؤشر `ptr` لا يتجاوز لحظة القرار `t` أبداً.
- الفريمات التنفيذية الثلاثة (15m/30m/1h) تُعالَل عند `t in index` = شمعة **مكتملة** عند `t`.
- الإشارة تُحسب عند إغلاق الشمعة (`bar_end`) لا بدايتها؛ `idx <= gate_idx` يمنع ملء في نفس لحظة الإكمال.
- حقائب الصناديق من `lows/highs` التاريخية فقط؛ الأحداث بزمن الحدث.
- كل رقم في التقرير من `summary_v23.json` / `trades_v23.csv` بعد تشغيل فعلي، والتشغيل يمر على: `yearly-coma assert` + `min_winner assert` + `streak <= 3 assert`.
