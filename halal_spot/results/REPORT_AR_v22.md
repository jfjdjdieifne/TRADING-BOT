## (5) إثبات صفر-نظرة-إلى-المستقبل

```
1078:            # feed completed 4H / 1H bars up to t (causal: <= t)
1083:                       and tf.index[ptr[(sym, stream)]] <= t):
 570:                         if b <= c <= t]        # الأحداث قبل لحظة القرار
 751:        if any(b <= c <= t for b, t in self.consumed):
```
- كل محرك يرى فقط `idx <= t` من الفريمات العليا (4H/1H/1D) — لا بيانات بعد لحظة الدخول.
- تعبئة الفريمات العليا بمؤشر `ptr` لا يتجاوز `t` أبداً.
- الإشارة تُحسب عند **إغلاق** الشمعة (`bar_end`) لا بدايتها.
- حقائب الصناديق تُرسم من `lows/highs` التاريخية لنطاق `max(0, idx-N)..idx` فقط.
- الأحداث (Sweep/BOS/FVG) تُسجَّل بزمن الحدث ولا تُستخدم قبله.
- كل رقم في التقرير مأخوذ حرفياً من `results/summary_v22.json` و`trades_v22.csv` بعد تشغيل فعلي.
