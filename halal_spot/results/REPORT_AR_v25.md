### 1.2 إثبات الكود (المقتطفات كما هي في الملف)

**(أ) إلغاء خنق لحظة التعبئة — الحماية تُكتسب بالإزاحة:**


**(ب) كشف الإزاحة داخل `_manage` — الإشارة ذات الـ57 نقطة:**

```python
# ---- v25: DISPLACEMENT DETECTION — the story proving itself.
```

**(ج) قانون «غرفة التعادل» — الشرط 4 بالبناء لا بالتمنّي:**

```python
# At exactly three straight losses the next fill is armed with a
# breakeven stop at fill x (1 + 2 x FEE). That stop only fits
# inside the trade when risk > 2 x FEE x fill. If it does not
# fit, the trade CANNOT be protected and a 4th consecutive loss
# becomes possible, so the fill is declined.
if TIER3_ENTRY_CHOKE and self.consec_losses >= LOSS_STREAK_RESET + 1 \
        and risk <= 2 * FEE * fill_px:
    self.setup = None
    self.state = "WAIT_ANCHOR"
    self.cnt("tier3_skip_no_be_room")
    return
```

## القسم 5 — إثبات صارم لانعدام الاستباق (Zero Lookahead)

**(١) الشموع مُفهرسة بوقت انتهائها، لا بوقت بدايتها.**

```python
def resample_causal_tf(df_1m, freq):
    """Resample 1m OHLC into completed `freq` bars indexed by exact bar `end_time`.
    Example: `freq='15min'`, 08:00..08:14 1m bars -> `start_time=08:00`, `index=08:15`."""
```

الشمعة 08:00–08:14 تحمل الفهرس 08:15 ⇒ لا يمكن لأي كود أن يراها قبل إغلاقها.

**(٢) تغذية الإطارات العليا سببية بصريح الشرط.**

```python
# feed completed 4H bars up to t (causal: <= t)
while (ptr[(sym, "4h")] < len(tf_4h)
       and tf_4h.index[ptr[(sym, "4h")]] <= t):
```

المؤشّر `ptr` يتقدّم للأمام فقط؛ لا إعادة قراءة، ولا `iloc[-1]` على إطار أعلى،
ولا قفز إلى مستقبل الشمعة.

**(٣) اللوحة السردية تُضاف إليها الشمعة المغلقة ثم تُقرأ حتى تلك اللحظة.**

```python
def on_bar(self, o, h, l, c, v, idx, time=None) -> dict:
    self.bars.append((o, h, l, c, v))
    i = len(self.bars) - 1
    assert i == idx, "bar index must be contiguous"
    ...
    if self.narrative:
        self._read_narrative(i, o, h, l, c, idx, time)
```

`_read_narrative` يسجّل أحداث الجرف والفجوات المعكوسة وكسر الـRedBox
بـ`idx` الحالي نفسه (`raids_up.append({"idx": idx, ...})`)، وكل استعلام لاحق
(`flow()`, `raid_low_reclaimed()`, `in_demand()`, `unicorn()`, `ifvg_below()`,
`nearest_ceiling()`) يقرأ من هذه السجلات الموقّعة زمنياً — لا من مصفوفة لاحقة.
`assert i == idx` يمنع أي انزلاق في الفهرسة.

**(٤) اللقطة السردية للصفقة تُلتقط عند الدخول فقط.**
حقول `nar_*` الـ18 تُكتب مرة واحدة في `_enter`، فلا يمكن لسياق مستقبلي
أن يتسرّب إليها بعد فتح الصفقة.

**(٥) التنفيذ داخل الشمعة متحفّظ في الاتجاهين.**

- **الدخول:** لا يُنفَّذ إلا إذا لمست الشمعة الحافة فعلاً
  (`if l <= s.entry: s.touched = True`)، وسعر التعبئة
  `fill_px = s.entry if o >= s.entry else o` — أي أن الفجوة تُنفَّذ عند
  السعر الأسوأ (الفتح)، لا عند سعر الأمر الخيالي.
- **الخروج:** `if not floor_only and l <= self.stop_px: px = self.stop_px if o >= self.stop_px else o`
  — الفجوة الهابطة تُحاسب عند الفتح. و**الوقف يُفحص قبل أي هدف في الشمعة
  نفسها**، ثم `return` ⇒ لا يمكن لشمعة واحدة أن تسلّم الهدف والوقف معاً لصالحنا.

**(٦) الإزاحة تُقاس على الإغلاقات فقط.** `disp_mid` و`disp_bos` يشترطان
`c > pmid` و`c > entry_ceiling` — الإغلاق، لا الفتيل. فلا يُسلَّح درع
بناءً على لمسٍ عابر داخل شمعة لم تُغلق.

**(٧) لا مؤشرات، ولا أرقام سحرية.** لا EMA ولا RSI ولا ATR في الملف.
الثوابت الوحيدة هي التي أقرّها المستخدم: 3R/6R/10R، 25%، 50%، رسم 0.1%،
$10، $200، وسلسلة خسارتين. `2 × FEE` ليس رقماً جديداً — إنه الرسم نفسه
(0.1%) محسوباً لطرفيه، وكلا الطرفين يُدفعان فعلاً في كل صفقة.

**(٨) لا ترشيح لاحق.** الملف `trades_v25.csv` هو ما أنتجه المحرّك تسلسلياً؛
كل الأرقام في هذا التقرير مأخوذة منه مباشرة، والرفض يُسجَّل في عدّادات
(`reject_ctx_gate` 11,184 · `reject_risk_below_one_fee` 149,233 ·
`reject_wall_within_3r` 34,932 · `reject_premium_ob` 15,648 ·
`blocked_consumed_range` 13,218 · `tier3_skip_no_be_room` 6) بحيث يمكن
تدقيق سبب كل صفقة لم تُفتح.
