### 1.5 الاكتشاف الجديد الأهم: الرسم يخلق تنافراً بين **عدد** الفوز و**قيمة** الفوز

الوقف الهجين صغّر `1R` ⇒ نفس الحركة السعرية تعطي R أكبر ⇒ **فائزون أكثر**:

| | v25 (وقف HTF) | **v26 (وقف هجين)** |
|---|---|---|
| وسيط المخاطرة | 0.4741% | **0.3267%** |
| فائزون | 51 | **70 (+37%)** |
| ≥4R / ≥10R | 13 / 3 | **18 / 6** |
| **متوسط ربح الصفقة الفائزة** | **$5.51** | **$4.40 (−20%)** |
| متوسط الخسارة | −$1.84 | −$1.52 |
| الصافي | **+42.14%** | +31.90% |

السبب محاسبي بحت: قفل الهدف مُعدَّل بالرسم
`lock = (E·(1+FEE) + 3R·risk)/(1−FEE)`، فصافي الفوز +3R يساوي
`3 × risk − 0.2%` من القيمة الاسمية. عند مخاطرة 0.16% يدفع الفوز ~0.5%،
وعند 0.65% يدفع ~2%. **الوقف الضيّق يصنع فائزين أكثر وأرخص.**
هذا هو القيد الحقيقي الذي يحكم النظام كله، وهو يفسّر لماذا لا يمكن شراء
نسبة الفوز بالرسم: كل نقطة نسبة فوز تُشترى بتقليص `1R` تُكلّف نقاطاً من الصافي.

### 1.6 إثبات الكود للتغيير الوحيد المُعتَمَد في v26

```python
# v26 CRIME-1 CORRECTION: the HTF floor is a FALLBACK, not a default.
# Inflating 1R does not move the +3R lock any closer to the delivery
# point - the audit measured the 4H range top at a median 7.78R away on
# LOSERS vs 6.59R on winners - but it does halve the R multiple every
# winner books and it puts the stop below the structure that actually
# invalidated the setup. So: widen ONLY when the LTF stop is too small
# to pay the round-trip fee (the 2023-25 coma case).
_ltf_risk = entry - stop
_need_htf = (STOP_SOURCE == "htf"
             or (STOP_SOURCE == "hybrid"
                 and _ltf_risk <= 2 * FEE * entry))
if _need_htf:
    ...  # widen to the HTF demand floor
elif STOP_SOURCE == "hybrid":
    self.cnt("stop_kept_ltf")
```

العدّادات: `stop_kept_ltf` = **43,225** · `stop_widened_to_htf` = **144,878**.
أي أن الهجين وسّع في 77% من الحالات (حيث الوقف الضيّق لا يغطي الرسم، أي
2023–2026 تحديداً) وأبقى الوقف الضيّق في 23% — وهذا بالضبط ما منع
عودة غيبوبة v22 وأحيا 2024/2025 من 14 إلى **47 صفقة لكل سنة**.

كل ما عدا ذلك في v26 مطابق لـv25: البوابة السردية، درع `MID+BOS`،
خنق الحالة الثالثة، وقانون غرفة التعادل (`tier3_skip_no_be_room` = 3 مرات).

## القسم 5 — إثبات صارم لانعدام الاستباق (Zero Lookahead)

v26 يرث كل آليات v25، ويضيف واحدة جديدة. كلها سببية:

**(١) الشموع مُفهرسة بوقت انتهائها.**
`resample_causal_tf`: الشمعة 08:00–08:14 تحمل الفهرس **08:15** ⇒ لا تُرى قبل إغلاقها.

**(٢) تغذية الإطارات العليا سببية بصريح الشرط.**
```python
while (ptr[(sym, "4h")] < len(tf_4h) and tf_4h.index[ptr[(sym, "4h")]] <= t):
```
المؤشّر يتقدّم للأمام فقط؛ لا إعادة قراءة ولا `iloc[-1]` على إطار أعلى.

**(٣) اللوحة تُضاف إليها الشمعة المغلقة ثم تُقرأ حتى تلك اللحظة.**
```python
def on_bar(self, o, h, l, c, v, idx, time=None):
    self.bars.append((o, h, l, c, v))
    i = len(self.bars) - 1
    assert i == idx, "bar index must be contiguous"
```
و`_read_narrative` يسجّل كل حدث بـ`idx` الحالي نفسه.

**(٤) الوقف الهجين — الجديد في v26 — يُقرَر من معطيات لحظة الدخول فقط.**
```python
_ltf_risk = entry - stop                       # كلاهما معروف عند الإعداد
_need_htf = (STOP_SOURCE == "htf"
             or (STOP_SOURCE == "hybrid" and _ltf_risk <= 2 * FEE * entry))
```
لا يستعمل أي شمعة لاحقة، ولا أي قمة/قاع لم يُؤكَّد، ولا قيمة مستقبلية.
وصناديق HTF التي يُبحث فيها عن الأرضية مشروطة بـ`b.state == "ACTIVE"`
و`b.y_bottom <= entry <= b.y_top` — أي صناديق حيّة عند تلك اللحظة.

**(٥) اللقطة السردية تُلتقط مرة واحدة عند الدخول** (18 حقلاً `nar_*`)،
فلا يتسرّب سياق لاحق إلى صفقة مفتوحة.

**(٦) التنفيذ داخل الشمعة متحفّظ في الاتجاهين.**
- دخول: `if l <= s.entry: s.touched = True` ثم `fill_px = s.entry if o >= s.entry else o`
  ⇒ الفجوة تُنفَّذ عند السعر الأسوأ.
- خروج: `if l <= self.stop_px: px = self.stop_px if o >= self.stop_px else o`
  ثم `return` ⇒ **الوقف يُفحص قبل أي هدف في الشمعة نفسها**، ولا تسلّم شمعةٌ
  واحدة الهدفَ والوقفَ معاً لصالحنا.

**(٧) الإزاحة تُقاس على الإغلاقات فقط** (`c > pmid` و`c > entry_ceiling`)،
فلا يُسلَّح درع بفتيلٍ داخل شمعة لم تُغلق.

**(٨) قفل الهدف مُعدَّل بالرسم مقدَّماً:**
`lock = (E·(1+FEE) + 3·risk)/(1−FEE)` ⇒ لا تُسجَّل صفقة فائزة بصافي دون +3.00R،
ولهذا `min_winner_R = 3.00` بالضبط وليس 2.9.

**(٩) لا مؤشرات ولا أرقام سحرية.** لا EMA/RSI/ATR. الثوابت: 3R/6R/10R،
25%، 50%، رسم 0.1%، $10، $200، وسلسلة خسارتين. `2 × FEE` هو الرسم نفسه
لطرفيه — وكلاهما يُدفع فعلاً.

**(١٠) التشريح نفسه سببي.** كل ميزة في `audit_v25_master.py` و`audit_v26_invalidation.py`
تُحسب من `seg = tf.iloc[lo:pos+1]` أي **حتى شمعة الدخول ضمناً** ولا شيء بعدها،
ومسارات ما بعد الدخول تُستعمل **لتقييم قاعدة خروج** لا لاتخاذ قرار دخول.
ولهذا وُسمت كل نتيجة في التقرير بـ`[PRE-ENTRY]` (سببية قابلة للشحن)
أو `[PATH]` (تقييم قاعدة خروج).
