# `scalping/` — نظام سكالبينغ آلي 1m/5m (تحليل + باك تست + بوت حي + ماسح عملات)

> هذا الملف **جديد تماماً** ولا يمسّ استراتيجية QuantConnect الحالية ولا أي ملف
> من ملفاتها. كل شيء هنا مستقل داخل `scalping/`.

---

## 1) وين الاستراتيجية؟ → **`STRATEGY.md`** (امر واحد: `python3 run_strategy.py`)

**الاستراتيجية اسمها `MOMENTUM-X`**: بوت زخم يمسح **كل عملات Binance**، يختار
الأقوى زخماً بين العملات السائلة، ويدخل بس لما **12 شرط مفصّل** يتحققوا مع بعض
في افتتاح لندن/نيويورك. الكل بـ `strategy.py` + `live/multi_bot.py` + `scanner.py`.

**نتائج مفصولة (لا تخلطها ببعضها):**

- **V8.3 (استراتيجية منفصلة):** تجميع تاريخي لـ net-R حسب يوم/أسبوع/شهر الخروج:
  371/994 أيام، 179/348 أسابيع، 54/81 شهراً موجبة؛ المجموع +515.8R. هذا ليس
  محاكاة محفظة ولا نتيجة MOMENTUM-X. الرسم: `outputs/horizons_positive.png`.
- **مرجع زخم يومي منفصل (`run_momentum.py`):** Walk-Forward خارج العينة 2020→2026،
  محفظة 3 أصول +223.5%، t=2.98؛ وعند مضاعفة التكلفة المفترضة +171.6%، t=2.55.
- **MOMENTUM-X (قواعد 5m أعلاه):** مرشح/بوت تجريبي؛ لم يُثبت بعد على كامل
  Binance USDT-M. التفاصيل: `STRATEGY.md` و `RESULTS.md`.

**ببلاش؟** `run_demo.py` بلا حساب ولا إنترنت (مسارات رمزية)، و
`--mode paper --market futures` بداتا Binance العامة وأوامر وهمية بلا مفاتيح/إيداع.
(Testnet خيار منفصل لتجربة الأوامر — التفاصيل بـ `STRATEGY.md` §4).

## 2) شو عملياً بينعمل بهالملف

نظام كامل سبقي (zero-lookahead) على فريم 1m و 5m:

```
scalping/
├── scalping_engine/
│   ├── primitives.py   # ATR, swings سبقة, order blocks, FVG, sweeps, displacement, VWAP, شموع
│   ├── sessions.py     # جلسات UTC + فتحة الجلسة ORB (لندن/نيويورك/آسيا)
│   ├── confluence.py   # "درجة الصفقة الذهبية" (7 شروط مدرجة قابلة للقياس)
│   ├── engine.py       # محرك الإشارات + المحاكاة (سبقة، SL/TP داخل الشمعة، رسوم)
│   ├── metrics.py      # WR, PF, R, DD, t-stat, كلفة الرسوم/R
│   └── data.py         # بيانات المستودع المحلية (BTC 5m, XAU/NSX 1m)
├── live/
│   ├── binance.py      # عميل Binance REST + WebSocket (سبوت + فيوتشر، بدون ccxt)
│   ├── live_bot.py     # بوت رمز واحد: حي/ورقي/ريبي (tick-level sweep monitor)
│   └── multi_bot.py    # بوت متعدد العملات: يمسح السوق ويصفق كل شمعة مغلقة
├── strategy.py         # ★ الاستراتيجية: MOMENTUM-X، 12 شرط، قرار نقي سبقي
├── STRATEGY.md         # ★ قواعد MOMENTUM-X + فصل النتائج + التشغيل المجاني
├── scanner.py          # ماسح كل أزواج USDT على Binance Futures (+ --offline)
├── run_strategy.py     # ★ أمر واحد: القواعد + النتائج المفصولة + الإطلاق
├── run_momentum.py     # مرجع زخم يومي منفصل (Walk-Forward 2020→2026)
├── run_horizons.py     # تجميع تاريخي لدفتر V8.3 المنفصل حسب اليوم/الأسبوع/الشهر
├── make_horizons_chart.py  # رسم تجميع net-R التاريخي لـ V8.3
├── run_backtest.py     # باك تست على بيانات حقيقية
├── run_research.py     # شبكة parameters + train/test (+ --orb لبحث الجلسات)
├── run_confluence.py   # اختبار: هل الشروط المدرجة ترفع نسبة الفوز/الربح؟
├── run_demo.py         # إطلاق أوفلاين مستمر للبوت متعدد العملات (بلا مفاتيح/إنترنت)
├── cost_hurdle.py      # عتبة الكلفة الرياضية (الرسوم بوحدة R)
├── make_wr_rr_chart.py # رسم مقايضة نسبة الفوز / RR
├── expectation.py      # رياضيات المخاطرة والـ10x (Monte Carlo)
├── RESULTS.md          # كل النتائج بالأرقام
├── math_notes.md       # المرجع الرياضي والأدلة
├── config.json
└── outputs/            # النتائج المولّدة
```

**الاستراتيجية الأساسية:** `momentum` (MOMENTUM-X، 12 شرط، كل العملات).
أنماط البحث الأخرى: `sweep`، `ob`، `vwap`، `bos`، `reclaim`، `mr`، `orb`، `combo`.

## 3) كيف بتشغله

```bash
pip install -r requirements.txt

# ★ امر واحد: يعرض الاستراتيجية + النتائج المفصولة + طريقة الإطلاق
python3 run_strategy.py
python3 run_strategy.py --test        # يعيد الاختبارين القويين
python3 run_strategy.py --launch      # يطلق البوت الورقي ببلاش

# ★ الاختباران المرجعيان مباشرة (ليسا باك تست لـ MOMENTUM-X 5m)
python3 run_momentum.py               # مرجع زخم يومي Walk-Forward 2020→2026
python3 run_momentum.py --stress      # ضغط الرسوم المفترضة ×2
python3 run_horizons.py               # تجميع تاريخي لدفتر V8.3 المنفصل

# باك تست سريع على BTC 5m
python3 run_backtest.py --asset btc5m --years 2025 2026 --mode orb --rr 1.5 --max-bars 24

# بحث parameters مع تحقق خارج العينة (+ بحث ORB بـ18 تكوين)
python3 run_research.py --asset btc5m
python3 run_research.py --asset btc5m --orb

# الرياضيات: عتبة الكلفة + المرجع
python3 cost_hurdle.py
python3 expectation.py --win-rate 0.5 --rr 1.0 --trades 40

# اختبار الشروط المدرجة
python3 run_confluence.py --asset btc5m --mode orb

# ماسح كل العملات (Binance Futures) — أو نسخة أوفلاين للتجربة
python3 scanner.py --top 10
python3 scanner.py --offline

# بوت ورقي برمز واحد (داتا Binance العامة، بلا مفاتيح)
python3 -m live.live_bot --mode paper --symbol BTCUSDT --interval 5m --market futures

# ★ البوت الأساسي: يمسح كل العملات ويتداول MOMENTUM-X (يعيد المسح كل 30 دقيقة)
python3 -m live.live_bot --mode paper --scan --top 8 --entry-mode momentum \
    --min-confluence 0.4 --market futures

# إطلاق أوفلاين مستمر (نفس الحلقة، بلا مفاتيح ولا إنترنت — محاكاة واضحة)
python3 run_demo.py --symbols 4 --cycle-sec 60

# أو ريبي متعدد العملات على داتا المستودع
python3 run_live.py --mode replay --scan --top 3 --entry-mode orb --bars 300
```

**مهم:** الافتراضي `paper_only=true`. ما في طلب حقيقي إلا مع `--mode live` ومفاتيح
Binance بالبيئة. البوت بيتخلص مع **حساب Binance** (فيوتزر/سبوت).

## 4) النتائج الحقيقية (من بياناتنا المحلية، بعد الرسوم والانزلاق)

> الجداول الكاملة: **`RESULTS.md`** — والمرجع الرياضي: **`math_notes.md`**.

### عتبة الكلفة — المشكلة الرياضية الأولى
`cost_hurdle.py`: كلفة الصفقة = (رسوم + انزلاق) / عرض الوقف:

| الرسوم | stop 0.5% | stop 1% | stop 2% |
|---|---:|---:|---:|
| سبوت taker (0.1%) | 0.480R | 0.240R | 0.120R |
| سبوت BNB (0.075%) | 0.380R | 0.190R | 0.095R |
| فيوتشر taker (0.05%) | 0.280R | 0.140R | 0.070R |
| فيوتشر maker (0.02/0.05%) | 0.220R | 0.110R | 0.055R |

الحافة الصافية ل ORB على بياناتنا ≈ **0.02R/صفقة**. العتبة أكبر منها بـ **5–25×**.

### فخ الـ 90% — إثبات تجريبي (BTC 5m ORB، قبل الرسوم)
| RR | WR% | PF | net R |
|---:|---:|---:|---:|
| 0.2 | 75.1 | 0.923 | **−24.4** |
| 0.5 | 59.1 | 1.026 | +9.2 |
| 1.0 | 50.7 | 1.052 | +18.6 |
| 1.5 | 47.6 | 1.043 | +15.1 |
| 2.0 | 47.1 | 1.017 | +5.8 |

**75% فوز = خسارة، 50% فوز = ربح.** الرسم: `outputs/wr_rr_tradeoff.png`.

### ORB بعد الرسوم
| الإعداد | N | WR% | net R |
|---|---:|---:|---:|
| سبوت taker، sl=0.5 ATR | 1011 | 33.6 | −305R |
| فيوتشر maker، sl=1.0 ATR | 1021 | 40.4 | −143R |
| فيوتشر maker، sl=2.0 ATR | 983 | 40.5 | −113R |

أرخص رسوم + أعرض وقف = **لسا سلبي**. يتوافق مع الأدبيات (ORB على BTC/ETH:
PF 0.65–0.80، سلبي بعد الرسوم).

### هل الشروط المدرجة تنفع؟ (`run_confluence.py`)
| min_conf | N | WR% | net R | exp R |
|---:|---:|---:|---:|---:|
| 0.0 | 1045 | 39.4 | −169.5 | −0.162 |
| 0.5 | 1043 | 39.5 | −166.9 | −0.160 |
| 0.8 | 764 | 38.2 | −142.0 | −0.186 |

**الجواب: لا.** الشروط المدرجة ما رفعت نسبة الفوز ولا الربح.

### بحث ORB بـ train/test كامل (`run_research.py --orb`)
- TRAIN 2025، 18 تكوين بأرخص رسوم فيوتشر: **0/18 إيجابي** حتى قبل الرسوم
  (أفضلها gross −19.0R / net −69.0R، t=−4.54).
- TEST 2026 (held-out، أفضل 6): **0/6 إيجابي**، أفضلها net −40.9R.

### الشبكات الكاملة
- **BTC 5m 60 تكوين**: أفضل Train +8.7R → نفسه Test 2026 **−30.8R** (overfitting).
- **XAU 1m 60 تكوين**: **0/60** إيجابي حتى قبل الرسوم.

### هدفك اليومي بالأرقام (تفصيله في `RESULTS.md` §0)
على $100 بمخاطرة 1% ($1 = 1R) و6 صفقات/يوم: يوم +$15 يحتاج **+2.5R لكل صفقة**،
وربح أسبوعي +$35 يحتاج **+0.83R لكل صفقة**. الحافة المقيسة = **−0.13R**.

## 5) الجلسات وفتحة الجلسة والماسح متعدد العملات

بنيت طلبك حرفياً:

- `sessions.py`: لندن (07:00 UTC)، نيويورك (13:00)، الـ overlap، آسيا — مع كشف
  فتحة الجلسة (أول 15/30 دقيقة) وكسرها، سبقي ١٠٠%.
- `confluence.py`: درجة 0–1 من 7 شروط موضوعية (displacement، حجم، إغلاق بالطرف،
  عرض الشمعة، bias الفريم الأعلى، قوة الجلسة، نظام التقلب).
- `scanner.py`: بيمسح **كل أزواج USDT على Binance Futures** ويرتّب حسب
  `جودة = تقلب × درجة الالتقاء × قوة الجلسة`. **فلتر مرشحين، مو إشارة.**
- `live/multi_bot.py`: بياخد أفضل N رمز من الماسح، بيفتح WebSocket مجمع
  (`kline` + `aggTrade` لكل رمز)، وبيقيّم **كل شمعة مغلقة لكل عملة** بنفس
  محرك الباك تست. يعيد المسح كل 30 دقيقة. `--offline` للماسح بيشتغل بلا إنترنت.

## 6) البوت الحي — شو بيعمل بالضبط

- داتا حقيقية من Binance WebSocket (سبوت أو **USDT-M فيوتشر**، `kline_5m` +
  `aggTrade`)، لرمز واحد أو لكل الرموز المرشحة.
- كل شمعة 5m مغلقة بتحسب المؤشرات السبقة (ATR/swings/OB/FVG/sweeps/ORB/
  confluence) وبتشغّل نفس محرك الباك تست — **تحقّقنا من تطابق الباك تست والحلقة
  الحية** على آخر 400 شمعة (نفس الإشارات، نفس المخارج).
- **مراقبة نكّات (tick-level):** SL/TP ونصب السيولة بأجزاء الثانية، أسرع من
  انتظار إغلاق الشمعة.
- إدارة صفقات: SL/TP داخل الشمعة، breakeven عند 1R، خروج بالوقت
  (`max_holding_bars`)، **صفقة واحدة مفتوحة على الحساب كله**، حد أقصى صفقات/يوم،
  و**فرملة خسارة يومية**.
- `paper` افتراضي: داتا حقيقية، طلبات وهمية.
- `live`: طلبات حقيقية موقّعة (testnet أولاً). ما في طلب حقيقي بدون `--mode live`
  ومفاتيح API بالبيئة.

## 7) وش تعمل الآن (خطة صادقة)

1. **شغّل البوت الورقي** أسبوعين على داتا Binance العامة (`--mode paper --scan --top 8 --entry-mode momentum --market futures` بلا مفاتيح/إيداع، أو testnet لتجربة أوامر افتراضية) — بدون ما تخسر دولار، وشوف الـ paper PnL الحقيقي.
2. **المسار الواقع للربح الأسبوعي/الشهري:** حافة صغيرة × انضباط × وقت. على
   فريم 5m فوق تكاليف الرسوم، هالحافة **غير موجودة بالأدلة**. على $100،
   أهدافك اليومية تحتاج +0.8R..+2.5R بالصفقة (انظر `RESULTS.md` §0)؛
   البديل فريم أكبر (15m/1h) أو رأس مال أكبر أو استراتيجية V8.
3. **الماسح جاهز** يرشّح أفضل العملات لحظة فتح الجلسة — جرّب
   `python3 scanner.py --top 10` (أو `--offline` بلا إنترنت).
4. **الخطوة التالية الحقيقية للسكالبينغ:** داتا أصلية (دفتر الأوامر / تدفق
   الأوامر) وحافة أكبر من الرسوم — هاد مشروع بحث منفصل يحمل على هالمحرك
   ويُثبت خارج العينة.

## 8) الأمانة التقنية

- كل الـ primitives سبقة: pivot بتأكد بعد k شمعة، HTF متوافق مع زمن الإغلاق.
- الباك تست يشمل رسوم Binance الحقيقية + انزلاق، وSL/TP داخل الشمعة.
- البحث يشغّل الشبكة الكاملة ويطبع كل النتائج، والتحقق على فترة ما دربت عليها.
- لا في أرقام مزيفة. إذا الرقم سلبي، بروح يظهر سلبي.
