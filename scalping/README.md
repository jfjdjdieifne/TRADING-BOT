# `scalping/` — نظام سكالبينغ آلي 1m/5m (تحليل + باك تست + (bot) حي)

> هذا الملف **جديد تماماً** ولا يمسّ استراتيجية QuantConnect الحالية ولا أي ملف
> من ملفاتها. كل شيء هنا مستقل داخل `scalping/`.

---

## 1) الحقيقة أولاً — قبل أي شي (مهم جداً)

طلبك كان: **100 دولار → 1000 دولار بيومين**، و**نسبة ربح 90%**، وبوت يصفق بكسر
الثانية. أنا بنفّذ الطلب هندسياً بكل جدية، بس لازم أكون صريح معك بالأرقام،
لأن وعد غير حقيقي بيضرّك أكثر من أنه يفيدك:

| الادعاء | الحقيقة |
|---|---|
| نسبة ربح 90% على 1m/5m | **غير موجودة في الأسواق الحقيقية.** حتى أفضل أنظمة ICT الميكانيكية المستقلة: 29.6% WR، وبالحكم البشري 40.4% ([مصدر](https://offbeatforex.com/is-ict-strategy-profitable/)). ادعاءات 90% هي تسويق. |
| بوت سكالبينغ بيربح بيومياً | دراسة  Testing **2,160** استراتيجية سكالبينغ على دقائق 1m: **ولا واحدة ربحت بعد الرسوم**. حتى بوت عنده "رؤية مثالية" للشمعة الجاية بيربح 0.066% للصفقة، بينما كلفة الصفقة 0.17–0.22% ([مصدر](https://dev.to/walid_koussa_0941941b1fdb/we-backtested-2160-crypto-scalping-strategies-on-1-minute-data-none-of-them-beat-the-fees-3mii)). |
| 100$ → 1000$ بيومين | رياضياً: مع نسبة فوز 50% و 1:1، احتمال الـ10x خلال 40 صفقة = **0.00%** إذا خاطرت 1–2% باليوم، و**3.13%** إذا خاطرت 25% باليوم (واحتمال الإفلاس 38%). إنه قمار، مو استراتيجية. شغّل `python3 expectation.py`. |

**الخلاصة:** لا يوجد بوت يضمن ربح. أي حد بيبيعك هذا الكلام يكذب. اللي موجود فعلاً
هو **حافة صغيرة + إدارة رأس مال + وقت طويل**. استراتيجيتنا الحالية (V8) هي بالضبط
هذا: 7/7 سنين رابحة، t-stat 4–5، لكنها **استثمار شهور/سنين، مو سكالبينغ يومي**.

## 2) شو عملياً بينعمل بهالملف

نظام كامل، سبعي وسبقي للبيانات (zero-lookahead)، على فريم 1m و 5m:

```
scalping/
├── scalping_engine/
│   ├── primitives.py   # ATR, swings سبقة, order blocks, FVG, sweeps, displacement, VWAP, شموع
│   ├── engine.py       # محرك الإشارات + المحاكاة (سبقة، SL/TP داخل الشمعة، رسوم)
│   ├── metrics.py      # مقاييس صريحة: WR, PF, R, DD, t-stat
│   └── data.py         # تحميل بيانات المستودع المحلية (BTC 5m, XAU/NSX 1m)
├── live/
│   ├── binance.py      # عميل Binance REST + WebSocket (بدون ccxt)
│   └── live_bot.py     # بوت حي/ورقي/ريبي (tick-level sweep monitor)
├── run_backtest.py     # باك تست على بيانات حقيقية
├── run_research.py     # شبكة parameters + تحقق خارج العينة (train/test)
├── expectation.py      # رياضيات الـ10x بيومين (Monte Carlo)
├── config.json
└── outputs/            # النتائج المولّدة
```

**نمط الدخول المتاح:** `sweep` (نصب سيولة)، `ob` (order block)، `vwap` ( pullback للـVWAP)،
`bos` (كسر structure مع displacement)، `reclaim` (نصب ثم استرجاع)، `mr` (mean-reversion
للمتطرف)، `combo` (كلهم).

## 3) كيف بتشغله

```bash
# 1) تبعت المكتبات
pip install -r requirements.txt

# 2) باك تست سريع على BTC 5m (2025-2026)
python3 run_backtest.py --asset btc5m --years 2025 2026 --mode vwap --rr 2.5 --max-bars 24

# 3) بحث parameters مع تحقق خارج العينة (Train 2025 → Test 2026)
python3 run_research.py --asset btc5m
python3 run_research.py --asset xau1m

# 4) رياضيات الـ 10x بيومين
python3 expectation.py --win-rate 0.5 --rr 1.0 --trades 40

# 5) بوت حي (ورقي بفتراض — بدون فلوس حقيقية)
python3 -m live.live_bot --mode paper --symbol BTCUSDT --interval 5m --testnet

# 6) بوت حي (فلوس حقيقية — بعد ما تختبر ورقي على testnet)
python3 -m live.live_bot --mode live --symbol BTCUSDT --interval 5m --testnet
```

**مهم:** الافتراضي `paper_only=true`. ما في أي طلب حقيقي إلا إذا كتبت `--mode live`
بشكل صريح ووضعت مفاتيح Binance بالبيئة.

**بخصوص "محفظتي":** البوت بيتخلص مع **حساب Binance** (منصة تداول) عبر مفاتيح API —
هاد هو العملي للسكالبينغ (سيولة وسرعة أوامر). أما إذا كان قصدك **محفظة ذاتية
(self-custody wallet)** على بلوك-تشين، فهذي بنية مختلفة تماماً (DEX/On-chain،
gas، slippage عالي) وتحتاج تنفيذ منفصل. قل لي أي نوع بالضبط وبدعمك.

## 5) البوت الحي — شو بيعمل بالضبط

- داتا حقيقية من Binance WebSocket (`kline_5m` + `aggTrade`).
- كل شمعة 5m مغلقة بتحسب المؤشرات السبقة وبتشغّل نفس محرك الباك تست.
- **مراقبة نكّات (tick-level):** بكشف نصب السيولة (sweep) بأجزاء الثانية عبر
  آخر swing level معروف، أسرع من انتظار إغلاق الشمعة.
- إدارة صفقات: SL/TP، خروج بالوقت، حد أقصى صفقات/يوم، **فرملة خسارة يومية**.
- `paper` بفتراض: داتا حقيقية، طلبات وهمية — الطريقة الوحيدة المنطقية للاختبار.
- `live`: طلبات REAL موقّعة عبر REST (testnet أولاً).

---

## 6) وش تعمل الآن (خطة صادقة)

1. **شغّل البوت الورقي** على testnet أو على بيانات حية أسبوع كامل، وجمع النتيجة
   الحقيقية (paper PnL) — هيك بتعرف حقيقة الحافة بدون ما تخسر دولار.
2. **إذا الورقي ربح باستمرار** (t > 2، DD مقبول، لأشهر): ارفع رأس المال ببطء.
3. **المسار الواقعي للفلوس:** استراتيجية V8 الحالية (7/7 سنين، t=4–5) مع 1–2%
   مخاطرة باليوم، مركّب على سنين — هاد هو "استثمار 100 ألف وسليه سنين" اللي طلبت
   إياه فعلاً، وبأرقام موثّقة من مستودعنا ourselves.
4. **السكالبينغ اليومي** ممكن يضاف كطبقة صغيرة بعد ما يثبت نفسه ورقي لأشهر،
   وبحجم صغير جداً.

## 7) الأمانة التقنية

- كل الـ primitives سبقة (zero-lookahead): pivot بتأكد بعد k شمعة، HTF متوافق مع
  زمن الإغلاق، ما في أي قراءة للمستقبل.
- الباك تست بشمل رسوم Binance الحقيقية (0.075% taker / 0.02% maker) + انزلاق
  0.02%، و SL/TP اتنين داخل الشمعة (conservative).
- البحث بشغل **شبكة كاملة** وبطبع كل النتائج، مو بس الجميل منها. والتحقق على
  فترة **ما دربت عليها**.
- لا في أي نتائج مزيفة. إذا الرقم سلبي، بروح يظهر سلبي.
