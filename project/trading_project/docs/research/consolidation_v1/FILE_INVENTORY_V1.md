## What this does NOT establish

- It does not judge quality. `ORPHAN_CODE` means "nothing in this tree names it", not "this file is bad": dynamic imports, string-based lookups and external callers are invisible to an AST import scan.
- `has_test` is a **name-reference** fact: a test that mentions a module may not exercise it, and a module exercised through another module will look untested.
- `cited_in_docs` counts documents, not credibility, and one document repeated in two places counts twice.
- The class of a file is a rule applied to facts; a different rule would move files between classes without any file changing.
- It removes and moves nothing: the snapshot is a copy outside the repository.
- It does not tell the owner which class to keep; that is `CONSOLIDATION_PROPOSAL_V1.md`.
