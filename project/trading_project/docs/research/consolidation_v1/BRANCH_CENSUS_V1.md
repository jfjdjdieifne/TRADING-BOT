## What this does NOT establish

- It does not rank the branches or say which one is worth keeping: it counts commits and file changes, and a large diff is not an achievement.
- It does not read any file's content, so it says nothing about whether a branch's code runs, is tested, or is correct.
- It does not detect duplicated work across branches; that is `HIDDEN_WORK_SEARCH_V1.md`.
- Commit counts are not quality: a branch 200 commits ahead may contain nothing that the backbone lacks, and one 1 commit ahead may contain the only working implementation.
- It does not modify, merge, delete or tag anything.
