# السؤال Q06: الاختيار بين مصفوفات سعرية متعددة في المكان نفسه

## سجل البحث في المستوى الأول

- الكلمات/الأنماط المجربة في بحث المتن الكامل: `PD array; order block; fair value gap; breaker; mitigation block; rejection block; select.*(array|zone); which.*(array|gap|block)`.
- نوافذ هذا السؤال المطلوبة والمقروءة: 1/1. بعض النوافذ مشتركة مع أسئلة أخرى، ويعدها السجل العام مرة واحدة لكل موضع.

## ادعاءات المستوى الأول

- **K5-Q06-C01:** عند سؤال المتعلمين عن اختيار كتلة الأمر، يبدأ الشرح بفهم ما يرجح أن يفعله السعر وإلى أين يسحب. هذا يبين ترتيب التحليل قبل اختيار الكتلة، لا ترتيباً بين كتلة الأمر والفجوة والكسّار إذا اجتمعت.
- لم يُعثر في البحث المحدد على رتبة ثابتة بين المصفوفات المتطابقة مكانياً. أدلة K4a-Q06 تبقى مرجعاً سابقاً غير مكرر.

## ادعاءات المستوى الثاني

- **K5-Q06-S01 — ادعاء طالب منفرد:** يسرد الكاتب فجوة القيمة العادلة عادةً، مع كتلة أمر أو فجوة معكوسة أو كسّار أحياناً؛ لا يعطي قاعدة فصل أو مفاضلة عند التراكب.

## البدائل المشروطة والتقديرية

الوجهة المتوقعة والسياق يسبقان اختيار كتلة الأمر في المثال؛ لا توجد رتبة مصرح بها للمصفوفات المتجاورة. اختيار واحدة منها عند التداخل **تقديري / NOT_FOUND**.

مصطلحات البحث: PD array, order block, fair value gap, breaker, mitigation block, rejection block, choose, select, overlap, which array, same level.
