# الفجوات المتبقية بعد البحث

- **Q01:** أولوية الإطار/السحب عند التعارض وشروط تغييرها.
- **Q02:** جدول مايكل الكامل لأدوار الانحياز والإعداد والدخول والإدارة لكل نموذج.
- **Q05:** قائمة الإلزامي والاختياري الكاملة لكل من نموذج ٢٠٢٢ والدخول الأمثل وحساء السلحفاة والرصاصة الفضية.
- **Q06:** قاعدة الاختيار عند تراكب المصفوفات السعرية.
- **Q07:** المؤكد الإلزامي لكل نموذج وهل يكفي مؤكد واحد.
- **Q09:** قاعدة الأمر السوقي أو المحدد أو أمر الإيقاف ومستوى التنفيذ العام داخل المنطقة.
- **Q10:** تعريف إجرائي للسحب الواضح والسلوك المتوقع وترتيب قواعد الامتناع.
- **Q11:** الاختيار المشروط بين قاع كتلة الأمر ونصفها وذيل الشمعة والمقابض الثابتة عبر النماذج.
- **Q12:** هل يوضع الخروج قبل الهدف أو عليه أو بعده، ومتى تؤخذ الأجزاء.
- **Q13:** محفز نقل الوقف إلى التعادل أو التتبع العام والإطار المستخدم.
- **Q14:** حدث أولي حتمي عام للخروج قبل الهدف.
- **Q15:** قاعدة عامة لإعادة الدخول أو العكس وعدد المحاولات ومقدار التخفيض الثابت.
- **Q16:** تحويلات لكل الأدوات التي لم يسمها المصدر.

لم تُملأ أي فجوة من المعرفة الشخصية. الادعاءات الثانوية تحصر ما قاله كاتبان عن نموذج ٢٠٢٢ فقط ولا تغلق الفجوات الأولية.
