# copytrade-aggregator — نسخ الصفقات المجمّع

نظام تجميع إشارات نسخ التداول من متداولين محترفين عبر منصات متعددة، مع نظام تصنيف وتصنيف ثقة من 100 نقطة، وإشعارات تليجرام مع أمر `/details` لعرض تفاصيل كل متداول على حدة.

> ⚠️ **تحذير مهم:** جميع النتائج افتراضية (HYPOTHETICAL_) ولا تشكل نصيحة استثمارية. النظام لا ينفذ صفقات تلقائياً — كل توصية تتطلب قراراً يدوياً من المستخدم. لا ضمان للربح، والخسارة ممكنة مع أي رأس مال.

## مواصفات المشروع

| الميزة | التفاصيل |
|--------|----------|
| **الغرض** | تجميع توصيات المتداولين المحترفين من منصات متعددة |
| **عدد المنصات المدعومة** | 8 منصات (3 عامة، 5 تحتاج API Key) |
| **تصنيف المتداولين** | 4 فئات: PROFESSIONAL_ACTIVE / INACTIVE / REGULAR / SUSPICIOUS |
| **نظام الثقة** | من 100 نقطة بناءً على اتفاق المحترفين، جودة البيانات، قرب الدخولات |
| **حد التفعيل الأدنى** | 2 محترفين نشطين مستقلين متفقين على الأقل |
| **مسافة الدخول** | 1.5% (مت configurable لكل زوج) |
| **فصل السوق** | Spot و Futures منفصلان (لا يُخلط بينهما) |
| **إزالة التكرار** | الشخص نفسه يُحتسب مرة واحدة حتى لو ظهر في منصات متعددة |
| **إشعارات** | تليجرام مع أمر `/details` لعرض تفاصيل كل متداول |
| **تنفيذ تلقائي** | لا يوجد — توصية فقط، والقرار للمستخدم |

## كيف يعمل النظام

1. **جمع الإشارات:** يُجلب توصيات المتداولين من المنصات المختلفة (زوج، اتجاه، دخول، ستوب، هدف، رافعة)
2. **تصنيف المتداولين:** يُصنف كل متداول إلى واحدة من 4 فئات بناءً على إحصائياته الفعلية
3. **إزالة التكرار:** الشخص نفسه يُحتسب مرة واحدة حتى لو ظهر في منصات متعددة
4. **تجميع الإشارات:** تُ_group الإشارات المتفقة على نفس الزوج والاتجاه ونوع السوق (Spot/Futures)
5. **فحص قرب الدخول:** تُتحقق من أن مستويات الدخول متقاربة ضمن مسافة 1.5%
6. **فحص الحد الأدنى:** يتطلب 2 محترفين نشطين مستقلين متفقين على الأقل لإطلاق الإشارة
7. **حساب الثقة:** تُحسب درجة ثقة من 100 نقطة بناءً على عدد المحترفين، جودتهم، وقرب دخولاتهم
8. **إرسال التوصية:** تُرسل رسالة تليجرام مع ملخص التوصية وأمر `/details` للتفاصيل الكاملة


## أمر `/details` (تفاصيل متداول فردي)

عند الضغط على `/details <معرف المتداول>` في تليجرام، يعرض النظام صفحة تفصيلية تتضمن:
- المنصة ونوع السوق (Spot/Futures)
- مستوى الدخول كما ورد (لا تعديل)
- الستوب والهدف كما ورد من المصدر (لا اختراع)
- الرافعة كما ورد
- الإحصائيات: نسبة الربح، عامل الربح، السحب الأقصى، عدد الصفقات
- نافذة الأداء 6–12 شهر
- موثوقية البيانات (مؤكدة ✓ أو غير مؤكدة ✗)
- مصدر البيانات وحداثتها

## ملاحظات مهمة

1. **لا تنفيذ تلقائي:** النظام يعرض توصيات فقط، ولا يفتح أو يغلق أي صفقات.
2. **لا ضمان للربح:** جميع النتائج افتراضية. التداول ينطوي على مخاطر عالية.
3. **بيانات حقيقية مطلوبة:** للتشغيل الفعلي، تحتاج بيانات حقيقية من المنصات ومفاتيح API للمنصات التي تتطلبها.
4. **اختبار أولي:** يُنصح باختبار النظام على حساب تجريبي (Demo) لأشهر قبل استخدام مال حقيقي.
