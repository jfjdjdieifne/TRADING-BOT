# خطة دفعات Phase 2 — اقتراح فقط، غير منفذ

لا تبدأ عملية تفسير قبل اختيار المالك للدفعة وإكمال تحقق المصدر. العد موضوعي مبني على الكلمات الصريحة في عنوان/وصف الحلقة المسترجع، وليس قراءةً مفاهيميةً للكلام أو إعادة استخدام ملخصات المستودع.

| الدفعة المقترحة | المصادر الأولية المتاحة ذات metadata صريحة | كاملة المحتوى | شرط البدء |
|---|---:|---:|---|
| السيولة | 1: P04 | 0 | استرجاع بقية التفريغ وتوثيق الأصل |
| بنية السوق | 1: P04، نفس المصدر وليس درسًا إضافيًا | 0 | نفس الشرط؛ يمكن جمعها مع الدفعة السابقة |
| الأهداف | 0 | 0 | اكتشاف درس أصلي واسترجاعه أولًا |
| Fair Value Gaps | 0 | 0 | اكتشاف درس أصلي واسترجاعه أولًا |
| الأطر الزمنية والسياق | 0 | 0 | لا يكفي ورود Time & Price في عنوان قائمة غير مفتوحة |
| الدخول والإبطال | 0 | 0 | اكتشاف درس أصلي واسترجاعه أولًا |

عدد الدروس الفريدة ذات محتوى جزئي: **1**، لا 2. عدد الدروس الكاملة الجاهزة: **0**. بقية المصادر الأولية المسترجعة P01 وP02 وP03 وP05: أربع صفحات تعريف/تنقل/حساب غير مخصصة موضوعيًا؛ لا تُضاف إلى عداد الدروس. P06 صورة غير مسترجعة مستبعدة. S01 ثانوي فقط خارج دفعات كلام مايكل.

ترتيب مقترح لا تنفيذ:
1. دفعة تحقق وصول صغيرة: حفظ البايتات/النص المستخرج الكامل مع بصمته، استكمال نص الحلقة 3 والتحقق من المصدر والتوقيت، واسترجاع صورة أصلية واحدة وعرضها. إذا تعذر ذلك تبقى الدفعة غير جاهزة.
2. بعد اختيار المالك: السيولة وبنية السوق معًا من P04، مع الفصل بين النص الأصلي والاقتباس القصير وغياب الدليل. هذه المرحلة وحدها قد تسمح لاحقًا بالتحليل، وليس الآن.
3. اكتشاف محدود للمواضيع الصفرية، ثم إعادة العد بعد استرجاع فعلي؛ لا استخدام عدد 41 في القائمة كعدد مصادر قابلة للتحليل.
4. اختيار المالك للدفعة التالية؛ لا قواعد، عتبات، أوزان، تعديلات محرك أو تسوية تناقضات ضمن هذا التسليم.
