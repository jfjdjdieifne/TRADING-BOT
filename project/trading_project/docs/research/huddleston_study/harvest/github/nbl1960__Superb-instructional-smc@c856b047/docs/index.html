Installing on TradingView

Works on any TradingView plan, on NIFTY, BANKNIFTY, or any other symbol.

  1. 1Get the scriptTap "Get the Pine Script" above, then use GitHub's Copy raw file button to copy the full source.
  2. 2Open Pine EditorIn TradingView, open any NIFTY chart → bottom panel → Pine Editor.
  3. 3New blank scriptClick Open → New blank indicator, then delete the placeholder code.
  4. 4Paste & savePaste the copied script, then click Save and give it a name.
  5. 5Add to chartClick Add to chart. The zones, structure labels, and dashboard will appear on your NIFTY chart.

The NBL Sequence

Every signal the script considers is built from the same seven-part confluence check taught in the playbook — no single signal fires alone.

  • 01Higher-timeframe bias4H trend direction agrees with the trade direction.
  • 02Liquidity sweptBuy-side or sell-side liquidity has just been taken.
  • 03Structure shiftA confirmed CHoCH or BOS follows the sweep.
  • 04Zone strengthPrice is reacting from a demand/supply zone above the strength threshold.
  • 05Fair value gap qualityA high-quality FVG supports the move.
  • 06Order blockAn order block aligns with the setup.
  • 07Volume confirmationParticipation is above its rolling average.

Reading the grade: A+ / B / NO-TRADE

The script surfaces a live 0–100 confidence score and a count of how many NBL Sequence conditions are met. The playbook teaches you to translate that into three plain decisions:

A+High confluence

All seven NBL Sequence conditions align and the confidence score sits in its upper range. The playbook's full checklist is met — still not a guarantee, but the highest-quality setup the framework defines.

BPartial confluence

Most, but not all, conditions are met. The playbook treats this as a caution zone — smaller size, tighter risk, or wait for the missing condition to confirm.

NO-TRADELow confluence

Few conditions align, or signals conflict. The playbook's rule here is simple: stand aside and wait for the next sequence.
