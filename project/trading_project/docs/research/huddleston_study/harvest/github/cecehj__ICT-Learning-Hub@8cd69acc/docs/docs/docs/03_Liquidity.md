# Liquidity

Liquidity represents areas where many orders are likely positioned.

## Types of Liquidity

### Buy-Side Liquidity (BSL)

Liquidity located above previous highs.

Examples:
- Equal Highs
- Previous Swing Highs

### Sell-Side Liquidity (SSL)

Liquidity located below previous lows.

Examples:
- Equal Lows
- Previous Swing Lows

## Liquidity Sweep

A liquidity sweep occurs when price moves into a liquidity area, triggers resting orders, and then reverses or continues.

Liquidity concepts are commonly used in ICT and Smart Money Concepts analysis.
