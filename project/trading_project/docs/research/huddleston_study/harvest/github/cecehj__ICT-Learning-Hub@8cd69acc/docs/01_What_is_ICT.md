# What is ICT?

ICT (Inner Circle Trader) is a trading education framework developed by Michael J. Huddleston.

The methodology focuses on understanding market structure, liquidity, institutional price delivery, and price inefficiencies.

## Main Concepts

- Liquidity
- Market Structure
- Fair Value Gap
- Order Block
- Premium & Discount
- Trading Sessions

ICT concepts are widely discussed in trading communities and are used as a framework for technical analysis.
