# ICT Learning Hub

An open-source educational repository for learning ICT (Inner Circle Trader) concepts and Smart Money Concepts (SMC).

## About

This project organizes publicly available ICT concepts, market structure theory, liquidity concepts, and trading education materials.

## Topics Covered

- Market Structure
- Break of Structure (BOS)
- Market Structure Shift (MSS)
- Liquidity
- Fair Value Gap (FVG)
- Order Block
- Premium & Discount
- Trading Sessions

## Purpose

The purpose of this repository is educational.

This project does not provide financial advice or trading signals.

## Contents

- `/docs` : Educational documentation
- `/examples` : Simple examples
