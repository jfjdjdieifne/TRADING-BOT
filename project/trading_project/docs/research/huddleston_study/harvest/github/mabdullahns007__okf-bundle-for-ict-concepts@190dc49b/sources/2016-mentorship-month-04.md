# Scope
Fourth 2016 mentorship installment and the densest: fourteen lessons cataloguing ICT's complete array of institutional "blocks" and liquidity phenomena that underpin nearly all later ICT material.

# Contents
- Interest rate effects on currency pairs.
- Reinforcing liquidity concepts.
- Order blocks — definition, validation (later candle trading through the down-close candle's high), entries, and stop placement at the block's low or 50%.
- Mitigation blocks, breaker blocks, rejection blocks.
- Reclaimed order blocks, propulsion blocks, vacuum blocks.
- Liquidity voids and liquidity pools.
- Fair value gaps (FVG) — inefficiency in price delivery.
- Divergence phantoms; double bottoms / double tops.

# Key Themes
- Order blocks as footprints of institutional order flow, validated by displacement through a candle's extreme ([/concepts/fair-value-gap.md] companion concept).
- Mitigation logic: price returns to unfilled institutional interest before continuing.
- Breaker blocks flip roles after a liquidity run — failed order block becomes opposing support/resistance.
- Premium/discount placement determines which arrays are tradeable ([/concepts/premium-discount.md]).
