# Scope

A small set of four videos from September 2022 (three covering AM/PM session reviews on September 1, 2, and 6) plus a single January 3, 2023 review. All focus exclusively on the Emini S&P 500 futures contract during the 2022 bear-market period.

# Contents

Each video is an after-the-fact session breakdown: how the opening range formed, where price drew toward, which intraday levels were respected, and how the AM session compared with the PM session. The reviews demonstrate reading session structure on the ES with ICT framing rather than indicators — identifying dealing ranges, premium/discount positioning, and how the day's expansion and retracement unfolded relative to prior highs and lows.

# Key Themes

- AM versus PM session character and intraday session framing
- Dealing ranges and premium/discount array evaluation
- Draw on liquidity toward prior session highs/lows
- Time-of-day expectations for index futures delivery
- Post-review application of 2022 mentorship concepts to a live index chart
