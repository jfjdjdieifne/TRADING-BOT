# Scope
Fifth installment (first of the 2017 cycle, January content). Eighteen lessons introducing the Interbank Price Delivery Algorithm (IPDA) framework: 20/40/60-day data ranges, open float, interest rate drivers, and seasonal tendencies.

# Contents
- Quarterly shifts in IPDA data; using IPDA data ranges (20, 40, 60 trading days).
- Open float and defining its liquidity objectives.
- Defining institutional order flow / indexing.
- Using 10-year notes in analysis.
- Qualifying trade conditions and setups.
- Interest rate differentials; intermarket analysis.
- Bullish and bearish seasonal tendencies; ideal seasonal tendencies for currency pairs.
- Money management.
- Defining HTF PD arrays.
- Stop entry vs limit order entry techniques; position trade management.

# Key Themes
- The IPDA algorithm references lookback price arrays to seek liquidity — the mechanical basis of draw on liquidity.
- Open float: unfilled institutional orders from prior periods pull price toward them ([/concepts/premium-discount.md]).
- Interest rate differentials and bond yields as fundamental drivers behind currency delivery.
- Seasonality as a timing overlay on PD array signals ([/concepts/power-of-three.md]).
