# Scope
Second 2016 mentorship installment. Eight lessons translating the Month 1 market-engineering worldview into practical account growth: risk framing, realistic return expectations, and the psychology of losing well.

# Contents
- Growing small accounts — compounding with asymmetric risk.
- Framing low-risk trades — tight, logical stop placement.
- How traders make 10% per — realistic periodic targets.
- No fear of losing — reframing losses as business costs.
- How to mitigate losing streaks — position sizing discipline.
- Secrets to selecting setups — filtering for confluence.
- Market maker trap: false breakout lessons (two parts).

# Key Themes
- False breakouts as deliberate market maker traps that sweep liquidity before the true move.
- Risk-first thinking: define invalidation before entry, mirroring later optimal trade entry logic ([/concepts/optimal-trade-entry.md]).
- Trading premium/discount asymmetry so stops sit beyond manipulation wicks, not arbitrary levels.
- Psychological conditioning: consistency over home-run attempts.
