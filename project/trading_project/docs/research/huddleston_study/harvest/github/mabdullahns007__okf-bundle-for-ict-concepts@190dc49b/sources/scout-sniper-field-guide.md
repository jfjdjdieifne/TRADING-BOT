# Scope

The Scout Sniper series frames the trader as a marksman: scout the terrain on higher time frames to establish directional bias and key levels, then snipe a single precise entry rather than scattering trades. It is one of ICT's classic foundational forex programs.

# Contents

Eight volumes progressing from basic concepts to full trade execution — defining the scout phase (higher time frame analysis, draw on liquidity), the sniper phase (surgical entry timing inside killzones), and integrating both into a repeatable daily routine.

# Key Themes

- One trade, done well: quality of setup over quantity of trades.
- Top-down analysis: weekly/daily context determines which intraday setups are worth taking.
- Patience as an edge: waiting for price to reach predefined levels instead of chasing.
