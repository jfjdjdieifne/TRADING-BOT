## 🎯 One indicator. All the ICT tools you need.

- **Fair Value Gaps (FVG)** – instantly spot bullish/bearish gaps  
- **Market structure (BOS / CHOCH)** – never miss a trend shift  
- **Liquidity sweeps** – see where the smart money hunts stops  
- **Silver Bullet sessions** – London, NY AM, NY PM – color‑coded  
- **Daily / Weekly levels** – PDH, PDL, PWH, PWL, NY Open  
- **ATR‑based TP/SL** – dynamic targets, displayed on signals  
- **Live dashboard** – trend, FVG, session, ATR, signal – all in one place  

✅ Non‑repainting signals

## 🚀 Quick start

1. Copy the code into TradingView Pine Editor  
2. Save as `BAKOME ICT Institutional`  
3. Add to chart – **works on any timeframe** (M5 recommended)  

No complex setup. Just attach and trade with ICT logic.
